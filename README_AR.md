# محدد سرعة الهاتف — PhoneSpeedLimiter 1.1

تطبيق Android بسيط لتحديد **سرعة الإنترنت على الهاتف نفسه فقط**، بدون تعديل الراوتر وبدون Root.

## الجديد في 1.1 — التشغيل الدائم

- تشغيل تلقائي بعد إعادة تشغيل الهاتف عبر `BOOT_COMPLETED`.
- إعادة تشغيل بعد تحديث/استبدال التطبيق عبر `MY_PACKAGE_REPLACED`.
- خدمة VPN تعمل كـ Foreground Service وتستخدم `START_STICKY`.
- إذا أعاد Android إنشاء الخدمة، تسترجع آخر حدود Download/Upload المحفوظة.
- يدعم Android Always-on VPN صراحةً.
- زر داخل التطبيق يفتح إعدادات VPN لتفعيل Always-on.
- زر لطلب استثناء التطبيق من تحسين البطارية.
- إغلاق التطبيق أو مسحه من قائمة Recent Apps لا يوقف محدد السرعة.

> ملاحظة مهمة: لا يوجد تطبيق Android عادي يستطيع ضمان "لا يتوقف أبدًا" بصورة مطلقة. المستخدم أو النظام يستطيعان إيقافه عند Force stop، إلغاء إذن VPN، إلغاء Always-on، وضع التطبيق في Restricted، أو إزالة التطبيق. أقوى وضع بدون Root أو Device Owner هو: Foreground Service + START_STICKY + BOOT_COMPLETED + Always-on VPN + استثناء البطارية.

## الوظائف

- حد منفصل للتنزيل والرفع.
- القيمة `0` تعني غير محدود لذلك الاتجاه.
- يطبّق الحد على حركة تطبيقات الهاتف عبر VPN محلي.
- لا يحتاج إلى خادم VPN خارجي.
- يدعم TCP وUDP.
- واجهة عربية بسيطة.

## إعداد التشغيل الدائم لأول مرة

1. ثبّت التطبيق وافتحه.
2. أدخل سرعة Download وUpload.
3. اضغط **حفظ وتشغيل دائمًا**.
4. وافق مرة واحدة على طلب Android لإنشاء VPN محلي.
5. اضغط **فتح إعدادات Always-on VPN** واختر تطبيق "محدد سرعة الهاتف" ثم فعّل **Always-on VPN**.
6. اضغط **منع النظام من تقييد التطبيق** واسمح باستثناء تحسين البطارية / اختر Unrestricted إن ظهر هذا الخيار.

بعد ذلك، عند إعادة تشغيل الهاتف، يقوم Android أو مستقبل الإقلاع داخل التطبيق بإعادة تشغيل محدد السرعة تلقائيًا.

### Samsung / One UI

لزيادة الثبات أكثر، تأكد أيضًا أن التطبيق غير موجود في قائمة **Sleeping apps / Deep sleeping apps**، وأن إعداد البطارية له هو **Unrestricted / غير مقيّد** إذا كان هذا الخيار متاحًا في إصدار One UI لديك.

## كيف يعمل؟

Android لا يعطي التطبيق العادي صلاحية وضع QoS على كل الجهاز. لذلك يستخدم المشروع `VpnService` لإنشاء TUN محلي. مكتبة `hev-socks5-tunnel` تحول الحزم إلى SOCKS5 محلي، ثم `LocalSocksServer` يمررها إلى الشبكة الفعلية ويطبق محدد معدل إجمالي (Token Bucket) على الرفع والتنزيل.

## المصدر المفتوح المستخدم

المشروع يعتمد وقت البناء على:

- `heiher/hev-socks5-tunnel` — ترخيص MIT.
- الـ commit المثبت: `64cc609f945253b0e9ebc56317d544268f3c68c1`.

لا يتم تضمين كود المكتبة داخل هذا ZIP؛ يقوم `setup_dependency.sh` بتنزيله من GitHub.

## البناء

### Android Studio

1. افتح مجلد `PhoneSpeedLimiter`.
2. تأكد من تثبيت Android SDK 34 وNDK `29.0.14206865`.
3. من Terminal داخل المشروع شغّل:

```bash
./setup_dependency.sh
```

4. ثم Build > Build APK(s).

### Kali / Linux

```bash
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
./build_debug.sh
```

الملف الناتج سيكون عادة:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## ملاحظات

- الحد إجمالي للهاتف وليس حدًا مستقلًا لكل تطبيق.
- قد يظهر Burst قصير قبل استقرار السرعة.
- Android يسمح عادةً بـ VPN واحد نشط لكل مستخدم، لذلك VPN آخر قد يستبدل هذا التطبيق.
- إذا فُعّل Always-on ثم اختير VPN آخر، سيغيّر Android الـ VPN النشط.
- زر **إيقاف التشغيل الدائم** يعطّل علم التشغيل التلقائي داخل التطبيق، لكن إذا كان Always-on مفعّلًا من إعدادات النظام فيجب تعطيله من إعدادات VPN أيضًا.
